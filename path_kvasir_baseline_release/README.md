# PathMNIST + Kvasir-V2 DD Baseline Release

This folder packages the code and launch configs used for the PathMNIST / Kvasir-V2 IPC10 pilot.

It contains two adapted codebases:

- `ncfm_code/`: NCFM-derived code with PathMNIST, Kvasir-V2, M22 token-attention, and DR-LTM hooks.
- `hop_tm_code/`: HoP-TM-derived code with PathMNIST and Kvasir-V2 dataloader/config support.

Large artifacts are intentionally excluded: datasets, checkpoints, expert buffers, condensed `.pt` files, and result folders.

## What Is Included

| Path | Purpose |
|---|---|
| `ncfm_code/` | NCFM baseline / M22 / DR-LTM implementation adapted for MedMNIST and Kvasir-V2 |
| `hop_tm_code/` | HoP-TM implementation adapted for PathMNIST and Kvasir-V2 |
| `launchers/launch_path_kvasir_pilot_20260620.py` | Combined pilot launcher for PathMNIST references, Kvasir NCFM groups, and reduced-buffer HoP |
| `launchers/launch_kvasir_teacher_audit_20260621.py` | Kvasir teacher audit launcher |
| `launchers/launch_kvasir_full_dd_after_audit_20260621.py` | Select best ConvNet teacher, pretrain 20 NCFM premodels, then run DD |
| `configs/resolved_ncfm/` | Resolved NCFM YAML configs captured from the server |
| `configs/hop/` | HoP-TM IPC10 configs for PathMNIST and Kvasir-V2 |
| `scripts/` | Minimal shell entrypoints for server runs |

## Baseline Choices

### PathMNIST

- NCFM baseline reference: `Path_B_T1024`
- HoP paper reference: PathMNIST IPC10 `77.23 +/- 0.65`
- Image size: `32 x 32`

### Kvasir-V2

- Kvasir split: fixed stratified split generated by `launch_path_kvasir_pilot_20260620.py`
- Image size: `128 x 128`
- Selected NCFM teacher: `ConvNet-6 width=1.5 instance norm`
- Teacher audit result: ACC `88.06`, AUC `0.9902`, Macro-F1 `0.8801`, BACC `0.8806`

The Kvasir NCFM full DD launcher first reuses or trains 20 NCFM premodels, then runs:

| Group | Meaning |
|---|---|
| `Kvasir_B_NCFM_T4096` | NCFM baseline |
| `Kvasir_M22_SM_lam02_tau005_L1_nf256` | M22 discrepancy-guided token attention |
| `Kvasir_DRLTM_lam03_a100_L1_nf256` | DR-LTM / position-wise local token risk |

## Run On Server

Assume this folder is copied to:

```bash
/data/zengqiang/experiments/NCFMproject_0603/path_kvasir_baseline_release
```

### 1. Kvasir Teacher Audit

```bash
cd /data/zengqiang/experiments/NCFMproject_0603/path_kvasir_baseline_release/ncfm_code
DATA_DIR=/data/zengqiang/experiments/NCFMproject_0603/datasets bash ../scripts/run_ncfm_kvasir_teacher_audit.sh
```

`DATA_DIR` should point to the parent directory containing the prepared Kvasir-V2 data/split used by the NCFM Kvasir dataloader. If omitted, the script writes under the experiment root, which is only useful when your dataloader can prepare the dataset there.

### 2. Full Kvasir NCFM DD After Teacher Audit

```bash
cd /data/zengqiang/experiments/NCFMproject_0603/path_kvasir_baseline_release/ncfm_code
bash ../scripts/run_ncfm_kvasir_full_dd.sh
```

### 3. Combined PathMNIST + Kvasir Pilot

```bash
cd /data/zengqiang/experiments/NCFMproject_0603/path_kvasir_baseline_release/ncfm_code
bash ../scripts/run_path_kvasir_pilot.sh
```

### 4. HoP-TM Reduced-Buffer Kvasir Pilot

```bash
cd /data/zengqiang/experiments/NCFMproject_0603/path_kvasir_baseline_release/hop_tm_code
bash ../scripts/run_hop_kvasir_reduced_pilot.sh
```

## Important Notes

- `Kvasir_B_NCFM_T4096` at `128 x 128` is very slow on a single RTX 3090: about `18 s/iter`.
- For quick pilot runs, reduce `num_freqs` from `4096` to `1024/2048` and/or reduce `niter`.
- HoP-TM full reproduction requires expert trajectory buffers; the included HoP Kvasir config is a reduced-buffer pilot, not the final official-scale run.
- Do not commit generated folders: `data/`, `checkpoints/`, `results/`, `runs/`, `buffer/buffers/`, `wandb/`.
